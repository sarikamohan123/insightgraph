# InsightGraph Frontend

React + TypeScript frontend for visualizing knowledge graphs.

## Quick Start

```bash
npm install
cp .env.example .env
npm run dev
```

Visit `http://localhost:5173`

## Features

- Interactive graph visualization
- Create graphs from text
- Browse and search saved graphs
- API key authentication

See full documentation in the file or visit http://localhost:8000/docs for API docs.
